# Building Material Shop Management

A Python-based shop management project developed for managing a building material business.

## Project Features

* Product management
* Add and manage product details
* Selling price and product information
* Sales record management
* Simple GUI-based interface
* Data storage using JSON files

## Technologies Used

* Python
* Tkinter / GUI
* JSON

## Project Files

* `main.py` — Main program
* `gui.py` — Graphical user interface
* `products.json` — Product data
* `sales.json` — Sales records

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run:

```bash
python main.py
```

## Project Purpose

This project is designed to make building material shop management easier by providing a simple digital system for handling products and sales.
